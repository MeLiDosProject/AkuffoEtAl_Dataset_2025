# Metadata used by this release

The scripts and codebooks in this directory are copied from
[Data_Metadata_Conventions commit fc9034b](https://github.com/MeLiDosProject/Data_Metadata_Conventions/tree/fc9034b16a7ca1814ad2610ce73649fa09dc5701).
Importers use this copy by default so later changes to the shared repository
do not change this release. `MELIDOS_METADATA_ROOT` is an explicit override for
development; leave it unset when reproducing the release.

The source commit is `fc9034b16a7ca1814ad2610ce73649fa09dc5701`. `checksums.csv` records the bundled files.
